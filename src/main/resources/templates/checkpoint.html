这套体系回答一个问题：怎么证明你不是「看懂了」，而是「能改能跑」。 判据统一为：在动手项目里加一个组件 / 改一处机制，跑出可观察的差异，并说得出为什么。
分级：L0 复现 → L1 改一处 → L2 加组件（主判据） → L3 打通。 入门线是每个工具至少两条 L2 通过。

为什么必须先写预测： 改完再解释，人会自动为既成结果编理由。先写下预测，才能暴露真实的心智模型。 预测错不扣分，预测错但没发现自己错了才是问题。 因此未填预测时「运行验收」按钮会被锁定，且预测一旦提交即冻结、不可修改。
