MCP 连接管理

← 返回

通过 Model Context Protocol (MCP)，你可以让外部 AI 工具（如 Claude Desktop、Cursor、Cline） 直接操作你的 Lattice-Planner 数据——目标、任务、笔记、知识库检索等。

使用方式：生成一个 Token，然后在外部工具的配置文件中填入连接地址。

🌐 MCP 远程连接（Client）

连接外部 MCP Server（联网搜索、文件系统等），让 Agent 即插即用地获得外部能力。 配置方式：在 application.properties 中添加 mcp.client.servers.{name}.url。

MCP Client 未启用。在 application.properties 中设置 mcp.client.enabled=true 开启。
