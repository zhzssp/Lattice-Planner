一句话：登录后顶栏只留 **规划** 和 **知识**。思维模式只活在规划里。知识是 Git 体系的工作室（路径、资料、笔记），检验 / 缺口 / 接入降为工具。

---

## 1. 为什么现在显得干瘪

Dashboard 顶栏把「我的笔记」「知识仓库」和思维模式、偏好、MCP 排成一排按钮。看起来像知识产品的，只有 `/note`（MySQL 随手记：列表、标签、Markdown）。Git 路径、要点、认可笔记藏在另一颗按钮后面，点进去是运维分段 Tab。

Idea 要的不是再做一个笔记 App，也不是在 Dashboard 旁边挂五张运维页。要的是：**规划回答「今天干什么」；知识回答「体系是什么、怎么改」**。两套去处，一份状态。Git 仍是权威源。

---

## 2. 应用级导航

登录后（不含 login/register）所有业务页顶栏：

```
[ 规划 ]  [ 知识 ]                         [ 设置 ]
```

| 目的地 | 路由 | 里面有什么 | Agent |
|---|---|---|---|
| 规划 | `/dashboard`（任务增改仍走 `/memo/*`） | 原 Dashboard；执行 / 学习 / 规划三种密度 **只出现在这里** | chat / learn / plan |
| 知识 | `/codex` 起跳 | 体系 / 资料 / 笔记；工具为次级 | study / iterate / curate / verify |
| 设置 | `/preference/settings`（MCP 从设置页进） | 偏好；不进两个目的地的主分段 | 现有面板 |

硬约束：

- 不把三模式搬进知识页。
- 不把 PKM 与 Git 混成一个无来源列表。
- 不在知识目的地再养一份待办（投影任务只链回规划）。
- 不改 CHAT/PLAN cassette schema。
- 不把五页合成 SPA：仍多路由 + 共享 chrome。
- `learning-guides/` 整目录仍禁止写。

## 3. 知识目的地

```
[ 规划 | 知识 ]
[ 体系 | 资料 | 笔记 | 工具 ]
[ 当前页：大纲 / 阅读 / 编辑 ]
[ Agent 分栏 ]
```

| 分段 | 路由 | 主内容 |
|---|---|---|
| 体系 | `/codex` | 车站大纲；点站看 MUST/SKIP；行内改要点，确认后写入 `docs/learning-path.md`。投影任务链到 `/dashboard` |
| 资料 | `/codex/distill` | 原料列表；点一篇在本页阅读；蒸馏 / 出题是动作不是首页标题 |
| 笔记 | `/codex/notes` | 默认 Git `docs/notes/**` 可读可写。MySQL 随手记是「未晋升」收件箱。`/note*` 仍可编辑随手记，但顶栏算知识 |
| 工具 | `/codex/tools` | 接入 / 同步 / 写入开关；链到检验、缺口、策展。检验 `/codex/checkpoints`、缺口 `/codex/gaps`、策展 `/codex/curate` 保留，二级导航高亮「工具」 |

未接入仓库时，体系页横幅指向工具页接入，不强迫改 `application.properties`。

---

## 4. 编辑边界

| 资产 | 软件里 | 怎么落盘 |
|---|---|---|
| 路径 / 要点 | 体系页行内改 | 既有 `path.apply`（整站 PATH_DELTA），人确认 |
| Git 笔记 | 笔记工作室 | `DocWriteGuard` 白名单 `docs/notes/**`；不 commit |
| 随手记 PKM | 收件箱 + 原 `/note` 编辑器 | MySQL；`note.promote` 才进 Git |
| 论文 / md 资料 | 资料页阅读 | 只读；蒸馏 create-only |
| `learning-guides` | 可读 | 禁止 `doc.write` 覆盖 |

---

## 5. 规划目的地的连带改动

- 去掉顶栏「我的笔记」「知识仓库」。模式切换留在规划页内部。
- 学习模式笔记列：随手记仍可快速记；主入口改为「打开笔记工作室」。
- 任务「去学」链到知识的当前站（已有投影描述里的 Codex 链保持）。

## 6. 分期与验收

| 刀 | 用户能感到什么 | 验收 |
|---|---|---|
| 0 壳 | 顶栏只有规划 / 知识；知识落到路径，不是健康度 | Dashboard 无「我的笔记」对等按钮；知识页二级为体系/资料/笔记/工具 |
| 1 体系编辑 | 点车站能改 MUST/SKIP，确认后文件变 | `POST /api/codex/path/point` 写入后 `GET /api/codex/path` 反映新要点 |
| 2 笔记工作室 | Git 笔记可打开、可写；随手记可晋升 | `/codex/notes` 列出 NOTE 文档与未晋升 PKM |
| 3 资料阅读 | 点一篇原料能在资料页读到正文 | `GET /api/codex/doc/content` 返回文本 |
| 4 工具收口 | 接入 / 检验 / 缺口 / 策展从主分段消失 | 一级 Tab 不再含检验/缺口/策展；工具页能点进去 |

不在本期：知识图谱、自研第二套编辑器、把 `/note` 后台删掉、WatchService、默认打开 `pkm.rag.git.enabled`。

---

## 7. 和既有设计的关系

G11 把 Tab 改成路径→资料→检验…，产品仍像执行器。「学」做成第三套列表被明确禁止。本篇把 **应用级** 拆成规划/知识，把检验降进工具，并把「我的笔记」收进知识，而不是再加一个顶栏按钮。

P-UI-001（分栏几何）仍独立，不阻塞本篇 chrome。
